# SUPER LIBRARY 1.0 — First Public Stable Release 🎮

A primeira versão pública estável do **SUPER LIBRARY**, uma interface independente para **Snes9x** criada para transformar uma biblioteca local de Super Nintendo em uma experiência de navegação mais próxima de um console.

### Destaques

- interface visual inspirada no SNES;
- carrossel de jogos e capas;
- suporte a mouse, teclado e gamepad;
- Xbox/XInput, DualShock/DualSense e vários controles SDL/genéricos;
- instalação gerenciada do Snes9x + shaders ou uso de Snes9x existente;
- importação e organização de coleções;
- perfis PT-BR / USA / Europe / Japan / Auto;
- deduplicação pelo conteúdo real da ROM;
- busca de capas ausentes;
- Smart Refresh;
- música e efeitos de interface;
- R1/RB segurado durante o jogo para fechar Snes9x e retornar ao launcher;
- Python não é necessário para o usuário final.

### Primeiros passos

1. Baixe `SUPER_LIBRARY_Setup_v1.0.0.exe` abaixo.
2. Instale e abra o programa.
3. Use **SELECT → Choose Folder** para apontar sua biblioteca.
4. Use **Y → Download Snes9x and Shaders** ou selecione uma instalação existente.
5. Escolha um jogo e pressione **A / Cross**.

> SUPER LIBRARY não inclui ou fornece ROMs comerciais.
